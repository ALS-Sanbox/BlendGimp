## 0.5.3 release rule

BlendGimp 0.5.3 is a user-interface/usability patch over 0.5.2. It does not intentionally modify the accepted raster, synchronization, projection, paint-tool, routing, layer, or persistence architecture.

The Image & Material card is now production-focused, texture creation uses a modal properties dialog, and XCF file operations live under **Image Editor → Image → BlendGimp XCF**.
